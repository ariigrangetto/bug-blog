# Brief: BugBlog Portfolio Showcase Video

## Goal
Produce a high-impact, 30-second 16:9 portfolio video for **BugBlog**, a developer-focused issue tracking application with a distinct hacker/terminal neon-green matrix aesthetic.

## Target Audience
Engineers, recruiters, and technical leads viewing developer portfolios.

## Key Features & Visuals
1. **CRT & Terminal Boot Intro**: Scanlines, matrix code rain, terminal prompt typing `> bugblog --init`, glowing logo.
2. **Interactive Code Editor & Debugging**: Code snippet presentation, line highlight, status badges (`OPEN`, `RESOLVED`, `CRITICAL`), real-time error detection.
3. **Dashboard & Analytics**: Animated count-ups of metrics (Bugs Solved, Open Issues, Velocity), severities pie chart/bars in neon green & red.
4. **Outro & Stack Badges**: Call-to-action with React, TypeScript, Supabase, Tailwind CSS badges and portfolio links.
