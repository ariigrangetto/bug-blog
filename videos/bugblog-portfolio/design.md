# Design Specification - BugBlog Portfolio Video

## Theme & Mood
- **Style**: Cyberpunk Terminal / Matrix HUD / Developer IDE
- **Vibe**: Fast, technical, high-precision, sleek neon dark mode

## Color System
- `--bg-primary`: `#050a05`
- `--bg-card`: `#0a150a`
- `--bg-card-secondary`: `#0d1f0d`
- `--neon-green`: `#00ff41`
- `--neon-green-dim`: `#00cc33`
- `--neon-green-muted`: `#00882a`
- `--neon-red`: `#ff3333`
- `--border-glow`: `rgba(0, 255, 65, 0.25)`
- `--shadow-glow`: `0 0 25px rgba(0, 255, 65, 0.15)`

## Typography
- **Primary / Code**: `"Fira Code", "JetBrains Mono", monospace`
- **Headings / UI**: `"Share Tech Mono", monospace`

## Motion Tokens
- **Ease**: `power3.out` / `expo.out` for crisp terminal pops
- **Micro-effects**: Terminal cursor blinking, CRT scanlines overlay, ASCII grid background pulse
